## Skills pessoais e homelab

O catálogo de skills do usuário fica em `/home/homelab/Projects/skills/README.md`; os procedimentos ficam em `/home/homelab/Projects/skills/skills/<nome>/SKILL.md`.

Ao iniciar uma tarefa, consulte o catálogo para verificar as skills disponíveis neste repositório. Reavalie a seleção quando o objetivo mudar; não precisa reler o catálogo em cada mensagem da mesma tarefa. Leia somente as skills pertinentes antes de aplicá-las. Se o caminho estiver indisponível, informe a limitação e continue com o contexto disponível, sem inventar seu conteúdo.

Quando uma skill ajudar, diga brevemente qual será usada e por quê. Aplique-a diretamente quando isso já estiver coberto pelo pedido. Se ela representar uma etapa opcional, sugira seu uso sem interromper o trabalho autorizado. Não force skills em perguntas simples nem transforme sugestões em pedidos recorrentes de confirmação.

Para ideias ainda abertas, sugira `entrevistar-ideia` quando uma entrevista crítica puder esclarecer decisões; não inicie uma entrevista longa sem o usuário solicitá-la. Quando o usuário pedir continuidade entre sessões, use `retomar-trabalho`. Respeite as convenções do projeto atual e as permissões da sessão; a disponibilidade de uma skill não autoriza ações adicionais.
